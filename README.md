# استوديو المحادثة والبرمجة التفاعلية (Ollama Chat & Code Studio)

تطبيق مكتبي متكامل وفاخر يدمج بين **الشات التفاعلي المستمر (Interactive AI Chat)** و **محرر الأكواد الاحترافي ومستكشف المشاريع (Live Code Editor & Project Workspace)**، مع **خادم API محلي متوافق مع OpenAI للاستخدام المباشر داخل VS Code**، مدعوماً بنماذج Ollama المحلية (مثل `qwen2.5-coder` و `qwen3-coder` و `gemma`)، مع دعم كامل وأصيل للغة العربية باتجاه **RTL**.

---

## 🔌 خادم API المحلي لـ VS Code (OpenAI-Compatible Local Server)

يتضمن الاستوديو خادماً محلياً فائق السرعة متوافقاً تماماً مع مواصفات OpenAI API:
- **نقطة الوصول الأساسية**: `http://127.0.0.1:8000/v1`
- **المنافذ المدعومة**:
  - `GET /v1/models`: يعرض قائمة النماذج المثبتة في Ollama بتنسيق قياسي.
  - `POST /v1/chat/completions`: يدعم التوليد المتدفق الفوري (Streaming SSE) والتوليد العادي.
  - `GET /api/status`: فحص صحة الخادم وحالة الاتصال بـ Ollama.
  - `POST /api/agent/generate`: توليد مشاريع برمجية متعددة الملفات.

### التشغيل من الواجهة الرسومية:
1. افتح **☰ الخيارات ← الربط مع VS Code** ثم انقر على **🔌 خادم VS Code API** لتشغيل الخادم على المنفذ 8000.
2. يتغير المؤشر إلى **`🟢 نشط (8000)`** ويظهر زر **`[ 📋 نسخ ]`** لنسخ الرابط بضغطة واحدة.
3. انقر على **ℹ️ ربط VS Code** في القسم نفسه لعرض إعدادات الربط المباشرة مع إضافات VS Code.

### التشغيل المستقل عبر الطرفية (CLI):
```bash
python api_server.py --port 8000
```

### كيفية الربط مع VS Code:

#### 1. إضافة Continue (الخيار الموصى به للمساعد البرمجي في الشريط الجانبي):
في ملف `~/.continue/config.json`:
```json
{
  "models": [
    {
      "title": "Local Qwen Coder",
      "provider": "openai",
      "model": "qwen2.5-coder:14b",
      "apiBase": "http://127.0.0.1:8000/v1",
      "apiKey": "local"
    }
  ]
}
```

#### 2. إضافة Cline / Roo Code (لوكيل البرمجة الذاتي):
1. افتح إعدادات **Cline** أو **Roo Code** في VS Code.
2. اختر **API Provider**: `OpenAI Compatible`.
3. اضبط **Base URL**: `http://127.0.0.1:8000/v1`.
4. أدخل أي نص في **API Key**: `local`.
5. اختر اسم الموديل مثل `qwen2.5-coder:14b`.

## 🌟 الميزات المتقدمة للاستوديو (Studio Capabilities)

### 1. ⚡ التدفق الحي والاستجابة الفورية (Live Streaming Generation)
- توليد النصوص لحظياً رمزاً برمز (Token-by-Token) في فقاعة الشات.
- ظهور فوري للرد التوضيحي باللغة العربية مع مؤشر كتابة نابض وعداد للأحرف قبل اكتمال ملفات الأكواد.
- إدراج رقاقات الملفات التفاعلية بمجرد انتهاء التوليد.

### 2. 💻 محرر أكواد احترافي مع أرقام الأسطر وعارض الفروقات (Line Numbers Gutter & Diff View)
- **شريط أرقام الأسطر (Line Numbers Gutter)**: متزامن بدقة 100% مع التمرير (Scroll)، والتحرير، وتغيير الثيم (داكن / فاتح).
- **تبويب الفروقات (🔀 Diff View)**: مقارنة تلقائية بين النسخة السابقة والنسخة المعدلة لكل ملف، مع تلوين واضح (🟢 مضاف / 🔴 محذوف / 🔵 ترويسات).

### 3. 🪄 التصحيح الذاتي للأخطاء ومثبت الحزم الذكي (Self-Healing & Auto Package Installer)
- عند تشغيل أي كود وحدوث خطأ (Traceback / Exit Code != 0)، يظهر فوراً زر:
  - **`[ 🪄 أصلح هذا الخطأ تلقائياً / Auto-Fix ]`**: إرسال نص الخطأ الدقيق والكود إلى المساعد ليحلله ويقدم الكود المصحح ويحدثه في المحرر.
- كشف تلقائي عن المكتبات المفقودة (`ModuleNotFoundError` / `Cannot find module`) مع زر مباشر:
  - **`[ 📦 تثبيت {pkg} تلقائياً (pip/npm install) ]`**: لتثبيت الحزمة من داخل الكونسول بنقرة واحدة.

### 4. 📦 تصدير المشروع ZIP وفاحص المجلدات القائمة (Project Tools)
- **`[ 📦 تصدير ZIP ]`**: ضغط كافة ملفات المشروع في ملف `.zip` جاهز للنشر والمشاركة بنقرة زر مع خيار الفتح في مستعرض ملفات ويندوز.
- **`[ 📥 فحص المجلد / Scan Folder ]`**: استيراد أي مجلد موجود مسبقاً على جهازك وفهرسة ملفاته النصية والبرمجية تلقائياً ليتمكن المساعد من قراءتها وتعديلها.

### 5. 🟣 نماذج كلود الرسمية وميزة الـ Artifacts الحية (Claude Models & Live Artifacts)
- **نماذج Anthropic Claude**:
  - زر **🔑 مفتاح Claude** ضمن **☰ الخيارات ← النموذج والذكاء الاصطناعي** لإدخال واختبار وحفظ مفتاح الـ API (`sk-ant-...`).
  - دعم نماذج `Claude 3.5 Sonnet` و `Claude 3.5 Haiku` و `Claude 3 Opus` مباشرة في الشات وتوليد المشاريع.
- **تبويب المعاينة الحية للأرتيفاكتس (🎨 Live Artifacts)**:
  - عرض فوري وتفاعلي لصفحات وتطبيقات الويب (`HTML / CSS / JS / SVG`) داخل الاستوديو.
  - محول التجاوب: **`[ 💻 سطح المكتب ]`** مقابل **`[ 📱 حجم الجوال (375px) ]`** بتصميم هاتف ذكي أنيق.
  - زر فتح مباشر بملء الشاشة في المتصفح الافتراضي (Chrome / Edge).
- **بطاقات الأرتيفاكت التفاعلية في الشات**:
  - عند توليد أي صفحة أو كود ويب، تظهر بطاقة أرتيفاكت بنفسجية أنيقة مع أزرار المعاينة الفورية وفتح المتصفح وعرض الكود.
- **تشغيل وكيل Claude Code التفاعلي بنقرة واحدة (ollama launch claude)**:
  - افتح **☰ الخيارات ← النموذج والذكاء الاصطناعي ← 🤖 استخدام Claude** لاختيار طريقة الاستخدام، أو شغّل Claude CLI من تبويب الطرفية.
  - يفتح نافذة طرفية تفاعلية مستقلة تشغّل أداة Claude Code الرسمية مع ربطها تلقائياً بالنموذج المحلي المختار عبر Ollama في مسار مشروعك!
- **دعم منفذ Anthropic في خادم API المحلي**:
  - يدعم الخادم المحلي منفذ `POST /v1/messages` المتوافق مع معيار Anthropic Messages API.

## 🚀 التشغيل السريع

### البحث على الإنترنت داخل المحادثة

ثبّت المتطلبات ثم أعد تشغيل التطبيق:

```powershell
python -m pip install -r requirements.txt
python main.py
```

اختر وضع **بحث الإنترنت** فوق مربع الكتابة:

- **تلقائي** (الافتراضي): يبحث عند بدء الرسالة بـ `/search` أو طلب صريح مثل `ابحث على الإنترنت عن توثيق Python asyncio` أو `search the web for Python asyncio`.
- **مفعّل**: يبحث باستخدام الرسالة الحالية قبل كل رد.
- **متوقف**: يمنع البحث حتى مع `/search`.

مثال: `/search أحدث إصدار من Python`. تظهر حالة البحث ثم يجيب النموذج المختار مستعينًا بما يصل إلى خمس نتائج، وتظهر روابط المصادر وأزرار فتحها. يعمل ذلك مع Ollama، بما فيه `qwen2.5-coder:14b`، ومع Claude. كتابة اسم نموذج آخر في الرسالة لا تغيّر النموذج المختار.

يعتمد البحث على [DDGS](https://pypi.org/project/ddgs/) دون مفتاح API. يُرسل موضوع البحث الحالي إلى محركات البحث، ولا تُضاف إليه ملفات المشروع أو سجل المحادثة. النتائج مقتطفات بحث وليست قراءة كاملة للصفحات، وقد تكون غير كافية أو غير حديثة. عند فشل البحث أو غياب النتائج يظهر تنبيه واضح؛ لا تُحفظ المقتطفات في ذاكرة المحادثة.

يدعم `POST /api/agent/generate` الحقل الاختياري `"web_search_mode": "auto"` (أو `"on"` / `"off"`) ويعيد `web_search` لحالة البحث و`sources` للمصادر الفعلية عند إجراء بحث. منافذ التوافق `/v1/chat/completions` و`/v1/messages` لا تنفّذ البحث تلقائيًا.

اختبارات البحث دون اتصال أو توليد فعلي:

```powershell
python -m unittest test_web_search.py
```
